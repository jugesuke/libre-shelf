# データの管理

端末に保存した商品と即売会の記録を、まとめてファイルに書き出し、読み込む画面である。端末を替えるときや、ブラウザのデータが消えたときに備えるために使う。パスは `/data` で、メニューの「データの管理」から開く（[ナビゲーション.md](ナビゲーション.md)）。

## まとめて書き出す

「すべて書き出す」ボタンで、次の形の JSON を `libre-shelf-backup-YYYY-MM-DD.json`（日付は、端末のタイムゾーンで数えた書き出した日）としてダウンロードさせる。

```typescript
type BackupFile = {
  format: "libre-shelf-backup";      // ファイルの種類
  version: 1;                        // このファイルの形のバージョン
  exportedAt: string;                // 書き出した時刻（即売会/セッションのデータ.md の「時刻の書き方」）
  items: Item[];                     // 商品マスタ（商品マスタ.md の「データ」）
  history: EventSessionRecord[];     // セッションの履歴（即売会/セッションの保存.md）
  currentSession: EventSession | null; // 進行中のセッション（即売会/セッションのデータ.md）。なければ null
};
```

- 商品マスタやセッションの履歴の値が読めない（壊れている）ときは、書き出さずに「保存されているデータを読み込めないため、書き出せませんでした。」と、ボタンの左に destructive のアラートで表示する

## 読み込む

「読み込む」ボタンでファイルを選ばせる。ファイルの `format` を見て、`"libre-shelf-backup"` ならまとめて書き出したファイル、`"libre-shelf-session"` なら 1 件のセッションのファイル（[即売会/セッションの保存.md](即売会/セッションの保存.md) の「ファイルへの書き出し」）として読む。どちらのファイルも、`version` が `1` のものだけを読む。

### まとめて書き出したファイル

端末にあるデータと、次のように合わせる。

| データ | 合わせ方 |
|---|---|
| 商品 | `item_id` が同じ商品は、ファイルの内容で上書きする。端末にない商品は末尾に足す（[商品マスタ.md](商品マスタ.md) の「書き出しと読み込み」と同じ） |
| セッションの履歴 | `id` が同じ記録は足さない。端末にない記録を足す。ファイルの中で `id` が重なるときは、先のものだけを足す |
| 進行中のセッション | ファイルのものが進行中（`settled = false`）で、端末に進行中のセッションがないときだけ、ファイルのものを入れる。端末の値が壊れているときや、今のスキーマでないときは、アプリを開いたときと同じく、ないものとして扱う（[即売会/セッションのデータ.md](即売会/セッションのデータ.md) の「localStorage」）。端末にあるときは、ファイルのものを入れず、そのことを表示する。ファイルのものが `settled = true` のときは入れず、表示もしない |

- 読み込めたら、「商品N件、記録N件を読み込みました。」とトーストで表示する。商品の数は、ファイルの商品の数（`item_id` の重なりを除く）で、内容が同じで上書きしても変わらない商品も数える。記録の数は、履歴に足した件数で、進行中のセッションは数えない。進行中のセッションを入れたときは「進行中の即売会も読み込みました。」を、端末にすでにあって入れなかったときは「進行中の即売会は、すでにあるので読み込みませんでした。」を続けて、1 つのトーストで表示する
- 次のときは、何も変えずに「ファイルを読み込めませんでした。Libre Shelfで書き出したファイルを選んでください。」と、ボタンの左に destructive のアラートで表示する
  - ファイルが JSON でない
  - `format` が `"libre-shelf-backup"` でも `"libre-shelf-session"` でもない
  - `version` が `1` でない
  - 中の商品、記録、セッションが、今の形に合わない
- 端末の商品マスタや履歴が読めないとき、書き込みに失敗したときは、何も変えずに「データを保存できませんでした。端末の空き容量を確認してください。」と同じ場所に表示する。商品、履歴、進行中のセッションの 3 つを書き込む途中で 1 つでも失敗したら、書き込む前に控えた値に戻し、どれも変えない

### 1 件のセッションのファイル

[即売会/セッションの保存.md](即売会/セッションの保存.md) の「ファイルからの読み込み」のとおり、履歴に足す。

- 読み込めたら「「{即売会の名前}」の記録を読み込みました。」とトーストで表示する
- 読み込めないときと書き込みに失敗したときの表示は、まとめて書き出したファイルと同じにする

## 画面

- ページの幅は narrow、見出しは「データの管理」にする
- 「まとめて書き出す」と「読み込む」の 2 つの区画をカードで分け、それぞれに、何のための操作かを 1〜2 文で書く
  - まとめて書き出す: 「商品と、即売会の記録をすべて、1つのファイルに保存します。端末を替えるときや、データが消えたときに備えて取っておけます。」
  - 読み込む: 「「すべて書き出す」や「ファイルに書き出す」で保存したファイルを読み込みます。いまの端末にある記録は消えません。同じ商品は、ファイルの内容で上書きします。」
- ボタンは、カードの中の右寄せのボタンだけの行に置き、行は 2 行のアラートが入る高さを取っておく。失敗は、操作したボタンと同じカードの、ボタンの左に出す（[デザイン/index.md](デザイン/index.md) の「処理の失敗」）
- 画面の文言は、同人活動と関係のない技術の言葉（ファイルの形式の名前など）を使わない
