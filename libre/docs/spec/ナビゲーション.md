# ナビゲーション

画面を切り替えるメニューである。

## 表示

メニューは画面の上端のバーの下、左側の幅 `w-56` の列に表示する。ここでいう幅はビューポートの幅である。

- 幅が `md`（768px）以上なら、サイドバーとして表示する。サイドバーは本文を右へ押し出し、本文に重ならない
- `md` 未満なら、ドロワーとして表示する。ドロワーは本文の上に重ね、上端のバーより下にある本文を半透明の黒い覆いで隠す。上端のバーは覆わない

上端のバーには左から、ハンバーガーボタン、アプリのアイコン（`public/icon.svg`）、アプリの名前「Libre Shelf」を置く。どれも幅によらず表示する。

上端のバーの左のハンバーガーボタンで、メニューを開閉する。ボタンは幅によらず表示する。ボタンの `aria-label` は、開いているときは「メニューを閉じる」、閉じているときは「メニューを開く」にする。`aria-expanded` は、開いているときは `true`、閉じているときは `false` にする。閉じているときは、メニューの列も覆いも描画しない。

### 開閉の状態

| 場面 | 幅が `md` 以上 | `md` 未満 |
|---|---|---|
| 画面を開いたとき | 開いている | 閉じている |
| メニューの項目を選んだとき | 変えない | 閉じる |
| 覆いを押したとき | （覆いはない） | 閉じる |
| `Escape` キーを押したとき | 変えない | 閉じる |

- 「画面を開いたとき」は `Frame` を表示したときである。メニューの項目を選んで別のページに移ったときも、移った先の `Frame` を表示するので、これに当たる。そのため、`md` 以上でボタンでメニューを閉じてから項目を選ぶと、移った先ではメニューが開いている
- 表示している間に幅が変わったとき（ウィンドウの大きさを変える、端末を回すなど）は、開閉の状態を変えない。サイドバーとドロワーのどちらで表示するかは、そのときの幅に合わせて切り替える
- `Escape` キーは、フォーカスがどこにあっても受ける。閉じたあと、フォーカスは動かさない
- 開閉の状態は保存しない。画面を読み込み直すと、上の表のとおりに戻る

### 確かめ方

`e2e/` の Playwright のテストで、ビューポートの幅を変えて確かめる。

- 幅 412px で画面を開くと、ハンバーガーボタンが「メニューを開く」で、メニューの項目が表示されていない
- 幅 412px でメニューを開いて項目を選ぶと、移った先の画面でメニューが閉じている
- 幅 412px でメニューを開いて覆いを押すと、メニューが閉じる
- 幅 412px でメニューを開いて `Escape` キーを押すと、メニューが閉じる
- 幅 1280px で画面を開くと、メニューの項目が表示されている

## メニューの構成

メニューの項目はグループに分ける。項目が 1 つだけのグループは、グループの見出しを出さずに項目だけを表示する。

```
即売会           ← グループ「販売」（1 項目なので見出しなし）
商品管理         ← グループ「商品」（1 項目なので見出しなし）
データの管理     ← グループ「データ」（1 項目なので見出しなし）
```

- 「即売会」は `/event`、「商品管理」は `/items`、「データの管理」は `/data` に移る
- パス `/` はランディングページで、メニューの外に置く（[ランディングページ.md](ランディングページ.md)）
- どの画面にも当たらないパスでは、即売会の一覧（`/event` と同じ画面。メニューは「即売会」を選んだ状態）を表示する。URL は書き換えない

## 色

画面ごとに色を決める。

| 画面 | 色 | 選んでいる項目の文字の色 |
|---|---|---|
| 即売会 | `#e9004a` | `#ffffff` |
| 商品管理 | `#008814` | `#ffffff` |
| データの管理 | `#0073df` | `#ffffff` |

- 表の「色」は、その画面のプライマリカラー（`--primary`）の値で、「選んでいる項目の文字の色」は `--primary-foreground` の値である。`Frame` は、選んでいる画面の値を `html` 要素の `--primary`、`--primary-foreground`、`--ring` に設定する。`--ring` には「色」と同じ値を入れる
- 上端のバー、メニュー、選んでいる項目、ポインターを重ねた項目、本文の上端の帯の見た目と色は、[デザイン/index.md](デザイン/index.md) の「フレーム」のとおりにする。選んでいる項目（`Frame` の `currentTab` の項目）には `aria-current="page"` を付ける
- アプリのアイコン（積み上がった本）の各冊の色は、その画面の色と同じにする

`e2e/frame-colors.spec.ts` で、3 つの画面を開き、`aria-current="page"` の項目の背景の色と文字の色が上のとおりであることを確かめる。

## 画面の種類

メニューに出す画面のキーは、今は次のとおりである。この型は `NAV_PAGES` のキーから導くので、手で書かない。

```ts
type NavTabType = "event" | "items" | "data";
```

## 実装

- `src/app/nav-sections.ts` の `NAV_PAGES`: 画面ごとのキー、名前、色を定める。色は選んでいる項目の色（`color`）、ポインターを重ねたときの色（`hoverColor`）、`html` に設定するプライマリカラー（`theme`）で、どれも「色」の節のとおりに、`ui/src/palette.ts` の色の一覧から選ぶ。`NavTabType` は、`NAV_PAGES` のキーから導く
- `src/app/nav-sections.ts` の `NAV_GROUPS`: グループの見出しと、グループに入れる画面のキーを並べる
- `ui/src/frame/sidebar-frame.tsx` の `Frame`: メニューを表示するコンポーネント。`NAV_PAGES` と `NAV_GROUPS` を渡して使う。各ページは `currentTab` に自分のキーを渡す

画面を足すときは、次のことをする。

1. `NAV_PAGES` に画面を足す
2. `NAV_GROUPS` のどれかのグループにキーを足す
3. ページを `/{キー}` のパスに置く。メニューの項目を選ぶと、そのパスに移動する
4. ページでは、`Frame` の `currentTab` に自分のキーを渡す
5. この仕様の「色」の表に行を足す
