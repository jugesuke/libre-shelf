# ランディングページ

libre-shelf を初めて開いた人に、何ができるアプリかを紹介するページである。アプリの機能の画面とは別に、独立して置く。

## パス

- パスは `/` とする
- メニュー（[ナビゲーション.md](ナビゲーション.md)）には項目を置かない。アプリの機能の画面（即売会と商品管理の画面）を包む外枠（`ui/src/frame/sidebar-frame.tsx` の `Frame`。上端のバーとメニューを持つ）の中にも置かない。メニューは出さない
- アプリの機能の画面から、このページへ戻る導線は置かない

## 中身

[デザイン/index.md](デザイン/index.md) の「目指すもの」の「わかりやすい」「たのしい」に合わせ、平易で堅くない言い回しで書く。同人活動と関係のない技術の言葉（ファイルの形式の名前、サーバ、オフラインなど）は使わない。使い方は、使う人がする順に上から並べる。

画面の構成は、アプリの画面（[ナビゲーション.md](ナビゲーション.md)）とそろえる。上から次の順に置く。

| 区画 | 中身 |
|---|---|
| 上端のバー | アプリの画面の上端のバーと同じ見た目で、アプリのアイコン（`public/icon.svg`。積み上がった本）と「Libre Shelf」を置く。メニューを開くボタンは置かない |
| ページの見出し | 「同人誌即売会のためのレジ」。見出しの右に、始めるボタンを置く |
| 説明 | 「頒布しながら、会計のたびに記録が残ります。帰ってから、売れ方やお釣りの足り方を振り返れます。」 |
| 特長 | 下の「特長」の見出しと、表の 4 つの項目 |
| 使い方の流れ | 見出し「使い方の流れ」の下に、下の「使い方の流れ」の表の 5 つの段階を、番号を付けたカードで、表の順に上から 1 列に並べる |
| データの置き場所 | 見出し「データの置き場所」の下に、下の「データの置き場所」の文とアラート |
| 最後の始めるボタン | 「さっそく使ってみましょう。」の文と、始めるボタン |

### 始めるボタン

ページの見出しの右と、ページの最後に、同じ 2 つのボタンを置く。

| ボタン | 移る先 | 色 |
|---|---|---|
| 即売会を始める | `/event` | 即売会の画面の色 |
| 商品を登録する | `/items` | 商品管理の画面の色 |

### 特長

見出しは「頒布しながら記録して、あとで振り返る」にする。斜め読みでも目に留まるように、各項目の見出しは太字にし、記録することから振り返ることへの順に並べる。

| 見出し | 説明 |
|---|---|
| 頒布しながら記録 | 会計するだけで、時刻、冊数、知り合いかどうか、受け取ったお札や硬貨の枚数が記録されます。来場者の数も、ボタンひとつで記録できます。 |
| 売れ方を振り返る | 30分ごとの頒布冊数や、知り合いとそれ以外の内訳を見られます。 |
| お釣りを振り返る | お札や硬貨ごとに、両替をせずに済むには最初に何枚用意しておけばよかったかが分かります。次の釣り銭の用意に使えます。 |
| 委託元への連絡 | 委託元ごとに、売れた冊数と売上、返す冊数をまとめた文をコピーできます。そのまま委託元への連絡に使えます。 |

### 使い方の流れ

カード（`ui/src/components/card.tsx`）の見出しに、番号と段階の名前を書き（例: 「1. 商品を登録する」）、中身に説明を置く。説明の `**` で囲んだ言葉は、太字にする（`**` は表示しない）。

| 番号 | 段階 | 説明 |
|---|---|---|
| 1 | 商品を登録する | 頒布する本やグッズを登録しておきます。**ISDNを入れると**、isdn.jpに登録された情報から、**書名やサークル名を読み込めます**。 |
| 2 | 前日 | 持っていく本と値段（**おしながき**）、持ち込む冊数を登録しておきます。 |
| 3 | 会場で | **バーコードを読むだけで会計**できて、お釣りも計算します。**スマートフォンやタブレットのカメラでも読めます**。来場者の数やレジ金の出し入れも、ボタンひとつで記録できます。 |
| 4 | 撤収の前に | 残った本とレジのお金を数えて、**記録と合っているかを確かめます**。 |
| 5 | 帰ってから | 数え間違いを直して記録を保存します。**売上の集計や委託元への連絡**、お釣りが足りたかも、あとから見返せます。 |

### データの置き場所

- 本文で「アカウントは要りません。記録は、いま使っているこの端末の中に残ります。どこにも送らないので、会場で電波が届かなくても使えます。インターネットを使うのは、ISDNから商品を登録するときだけです。」と書く
- その下に warning のアラートで「ブラウザのサイトのデータを消すと、記録も消えます。残したい記録は「ファイルに書き出す」で保存しておいてください。」と書く

## 見た目

[デザイン/index.md](デザイン/index.md) に従う。

- 上端のバーは、アプリの画面の外枠（`ui/src/frame/sidebar-frame.tsx` の `Frame`）の上端のバーと同じ見た目にする。メニュー、メニューを開くボタン、本文の上端の帯は置かない
- ページの幅、外側の余白、ページの見出しと見出しの右の操作は、部品の `Page`（`ui/src/components/page.tsx`）の narrow で作る。背景は白（`--background`）にする
- 始めるボタンは `ui/src/components/button.tsx` の primary を使い、ボタンごとに、移る先の画面のプライマリカラー（`src/app/nav-sections.ts` の `event` と `items` の `theme`）にする。primary を 1 つの画面に 1 つまでとする決まり（[デザイン/index.md](デザイン/index.md) の「ボタン」）は、このページには当てはめない
- プライマリカラーは、始めるボタンのほかには使わない（[デザイン/index.md](デザイン/index.md) の「色」）
- 特長の見出しと、「使い方の流れ」「データの置き場所」の見出しは、見出し（中）（18px の太字）にする。カードの見出しは、カードの部品のもの（見出し（小））を使う。ほかの文は本文（14px）にし、「説明」の区画の文の色は `--muted-foreground` にする（[デザイン/index.md](デザイン/index.md) の「タイポグラフィ」）
- データの置き場所のアラートは `ui/src/components/alert.tsx` を使い、本文の下に置く
- 最後の始めるボタンは、「さっそく使ってみましょう。」の文の下に、ページの見出しの右と同じ順で横に並べる
- 特長の 4 つは、画面幅が 768px 以上なら 2 列、768px 未満なら 1 列で、表の順に並べる。カードは使わず、見出し（太字の本文）と説明を並べる
- 太字は、大きさを変えずに太さだけを変える（[デザイン/index.md](デザイン/index.md) の「タイポグラフィ」）
- 区画のあいだと、区画の中の要素のあいだの余白は、余白の決まり（[デザイン/index.md](デザイン/index.md) の「余白」）の値から選ぶ
- 画面の写真や図、アプリのアイコンのほかのアイコンは載せない

## 確かめ方

- `e2e/` の Playwright のテストで、`/` を開くと見出し「同人誌即売会のためのレジ」が出て、メニューを開くボタン（「メニューを開く」）が出ないことを確かめる
- ページの見出しの右と最後の、どちらの「即売会を始める」でも `/event` へ、「商品を登録する」でも `/items` へ移ることを確かめる
- 「使い方の流れ」のカードが、番号の順に上から並ぶことを確かめる
