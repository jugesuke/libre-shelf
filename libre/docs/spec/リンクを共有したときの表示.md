# リンクを共有したときの表示

SNS やチャットに Libre Shelf の URL を貼ったときに出る、タイトル、説明、画像（OGP）を決める。どのパスの URL を貼っても、同じものを出す。

## 入力

- ビルドのときの環境変数 `SITE_URL`: アプリを公開する場所の URL（例: `https://libre-shelf.example.com`）。末尾の `/` はあってもなくてもよい。パスを含んでもよい（`https://example.com/libre` なら、`og:image` は `https://example.com/libre/ogp.png`）。前後の空白は除いて扱い、空の文字列は渡さなかったものとして扱う
- `public/ogp.png`: 共有したときに出す画像

## 出力

`pnpm build` で作る `index.html` の `<head>` に、次の `<meta>` を置く。

| 属性 | 値 |
|---|---|
| `name="description"` | 頒布しながら、会計のたびに記録が残ります。帰ってから、売れ方やお釣りの足り方を振り返れます。 |
| `property="og:type"` | `website` |
| `property="og:title"` | Libre Shelf |
| `property="og:description"` | `name="description"` と同じ |
| `property="og:url"` | `SITE_URL` の末尾の `/` をすべて除き、`/` を付けたもの |
| `property="og:image"` | `SITE_URL` の末尾の `/` をすべて除き、`/ogp.png` を付けたもの |
| `name="twitter:card"` | `summary_large_image` |

- 説明の文はランディングページ（[ランディングページ.md](ランディングページ.md)）の「説明」の区画と同じにする
- `og:url` と `og:image` は絶対 URL でなければ読まれないので、`SITE_URL` から作る。`SITE_URL` を渡さずにビルドしたときは、この 2 つを置かず、ほかの `<meta>` だけを置く。手元での開発と e2e のテストでは `SITE_URL` を渡さずにビルドするので、このときにビルドを止めない
- `SITE_URL` が `http:` か `https:` の URL でないとき、またはクエリ（`?`）かフラグメント（`#`）を含むときは、ビルドを失敗させる
- `<meta>` を組み立てる処理は `shared/ogp/` に置き、`vite.config.ts` のプラグインが `index.html` に差し込む
- 公開する場所ごとに、デプロイするときに `SITE_URL` を渡す（例: `SITE_URL=https://libre-shelf.example.com pnpm deploy`）

## 画像

`public/ogp.png` は 1200×630 の PNG である。`scripts/generate-ogp.ts` が描いて書き出し、生成物を git で追跡する。描くにはブラウザ（Playwright の Chromium）と、Google Fonts からのフォントの取得が要るので、ビルドでは生成しない。メニューに出す画面（`src/app/nav-sections.ts` の `NAV_PAGES`）の色や数か、下の表の右の 1〜3 行目の文言を変えたら、`node scripts/generate-ogp.ts` を実行し直してコミットする。

見た目はランディングページに合わせる（[デザイン/index.md](デザイン/index.md)）。

| 部分 | 内容 |
|---|---|
| 背景 | 白 |
| 左 | アプリのアイコン。`public/icon.svg` と同じく、`shared/icon/book-icon.ts` の `buildBookIconSvg` に `NAV_PAGES` を渡して描く。縦横比を変えない |
| 右の 1 行目 | 「Libre Shelf」。太字、gray-900 |
| 右の 2 行目 | 「同人誌即売会のためのレジ」（ランディングページの見出し）。太字、gray-900 |
| 右の 3 行目 | 「頒布しながら記録して、あとで振り返る」（ランディングページの特長の見出し）。標準の太さ、gray-600（`--muted-foreground`） |
| 下端 | `NAV_PAGES` の各画面のプライマリカラー（`theme.primary`）を、`NAV_PAGES` の順に左から同じ幅で並べた帯。フレームの本文の上端の帯（[デザイン/index.md](デザイン/index.md) の「フレーム」）に倣う |

- フォントは BIZ UDPゴシックにする。読み込めなかったときは、代わりのフォントで描かずに生成を失敗させる
- 文字の大きさは、縮小して表示されても読めるように、デザインのテキストスタイルより大きくしてよい
- 大きさと位置の細かい値は `scripts/generate-ogp.ts` にあり、生成した画像を目で確かめて決める

## 確かめ方

- `SITE_URL` を渡したときと渡さないときの `<meta>` の組み立てを、Vitest のテストで確かめる
- `e2e/` の Playwright のテストで、`/` の `index.html` に `og:title` と `twitter:card` の `<meta>` があり、`/ogp.png` が PNG として取得できることを確かめる
- 画像の見た目は生成した `public/ogp.png` を開いて目で確かめる
