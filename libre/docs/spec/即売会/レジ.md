# レジ

即売会の開催中に、販売と来場者を記録する。タブで切り替える 1 ページの画面である。

## 販売

1. 商品を選ぶ。バーコードリーダー（HID 接続で、キーボードの入力として届く）か、端末のカメラ（[../バーコードのカメラ読み取り.md](../バーコードのカメラ読み取り.md)）で読む
2. 読んだ商品をカートに表示する（商品名、価格、数量）
3. 読み間違いや操作の誤りはカートから商品を取り消して直す
4. 複数の商品を 1 回の会計（1 件のトランザクション）にまとめられる
5. お釣りを計算する
6. 購入者の区分のボタンを押して、会計を確定する

### お釣りの計算

受け取った硬貨と紙幣に合わせて、金種のボタンを 1 枚につき 1 回押し、預かった額を積み上げる。

- 金種のボタンは 100、500、1000、2000、5000、10000 円の 6 つで、2 列に並べる。左から右、上から下の順に、100、500、1000、2000、5000、10000 円と置く。その下に、積み上げを 0 に戻す「クリア」ボタンを置く
- 画面には合計、預かった金額、お釣りの金額を表示する
- 押した回数を、金種ごとの枚数として会計に記録する（`tendered`、[セッションのデータ.md](セッションのデータ.md)）
- 1、5、10、50 円の硬貨のボタンは置かない。これらで払われたら、近い金額のボタンを押して確定する（50 円玉 2 枚なら 100 円を押す）。そのぶん、記録した金種は実際とずれる
- 金種のボタンを押したあとも、バーコードリーダーの入力を受け付ける

### 会計の確定

- 確定のボタンは「知り合い」と「知り合い以外」の 2 つである。どちらかを押したら、購入者の区分（`buyerType` が `acquaintance` か `stranger`）を付けて、トランザクションを保存する
- 確定のボタンを押せるのは、カートに商品があり、預かった金額が合計以上のときだけである。押せないときは、ボタンを押せない見た目にする
  - 金種のボタンを押していなければ、預かった金額は 0 円とする。そのため、合計が 1 円以上なら、ボタンを押すまで確定できない
  - 合計が 0 円（カートが価格 0 円の商品だけ）なら、金種のボタンを押さなくても押せる。そのときの `tendered` はどの金種も 0 枚になる
- トランザクションには預かった金種ごとの枚数（`tendered`）と、お釣り（`changeAmount`、預かった金額から合計を引いた額）を記録する。お釣りは 0 以上になる
- お釣りで渡した金種は記録しない。会計の作業を増やさないため

### 会計の取り消し

- 「会計一覧」ボタンを押したら、会計の一覧をダイアログで表示する
- 一覧にはトランザクションごとに、時刻、購入者の区分、商品、合計金額を表示する。取り消したものは取り消したと表示する
- どのトランザクションも削除のボタンで取り消せる。押したら確認ダイアログを出し、確かめたら `cancelled = true` にする

## 来場者の数え上げ

- 「来場者」ボタンを 1 回押すごとに、1 人と時刻を記録する（`visitorLogs`）
- 「直前の来場者を取り消す」ボタンで、最後の 1 件を取り消せる
- 販売とは別に記録する

## レジ金の出し入れ

開催中にレジ金を出し入れしたら（釣り銭の補充、売上の回収、両替など）、日時、入れた枚数、出した枚数、メモを記録する（`cashAdjustments`）。

- 「レジ金増減」ボタンを押したらダイアログを開く。ダイアログには記録した出し入れの一覧と、新しい出し入れの入力欄を置く
- 入力欄は「入れた」と「出した」の 2 つの列からなり、それぞれに 6 つの金種の枚数を入力する。両替なら両方の列に入力する（例: 10000 円札を 1 枚出し、1000 円札を 10 枚入れる）
- 枚数はブラウザの数値入力（`input type="number"`）で、0 以上の整数を入力する。入力していない欄と、0 以上の整数でない値を入れた欄は 0 とする
- どの欄も 0 枚なら、記録のボタンを押せない
- メモは任意で、文字の入力欄で入力する
- 日時は、記録のボタンを押した時刻とする
- 一覧には日時、金額（入れた金額 − 出した金額）、入れた金種と出した金種の枚数、メモを表示する。各行に削除のボタンを置く。削除のときに確認は出さない
- 1、5、10、50 円の硬貨は記録しない

## 商品・価格編集

`phase` を変えずに、商品と価格を編集する画面である。終えたらレジに戻る。

- おしながき
  - 商品の追加と削除、価格、委託元名、預かり部数を変えられる。足す商品は商品マスタ（[../商品マスタ.md](../商品マスタ.md)）から選ぶ
  - 変更は、ダイアログの「保存」を押したときに localStorage に保存する。「キャンセル」で閉じたら保存しない。オフラインで使える
  - レジの途中で新しく足した委託物は、預かり部数を `consignedStock` と、持ち込んだ在庫（`openingStock`）に入れる。すでにある商品の持ち込み数は変えない
  - 持ち込み数の入力欄は新しく足した自サークルの頒布物にだけ表示する。入力した数を、持ち込み予定数（`plannedStock`）と持ち込んだ在庫（`openingStock`）に入れる
  - ダイアログの「保存」を押したときに、持ち込み数と預かり部数の入力欄を確かめる。自サークルの頒布物の持ち込み数は 0 以上の整数、委託物の預かり部数は 1 以上の整数でなければならない。空欄も合わないものとする。合わない欄が 1 つでもあれば、ダイアログを閉じず、何も保存せずに、その入力欄の下に「持ち込み数を入力してください（0以上の整数）。」か「預かり部数を入力してください（1以上の整数）。」を表示する。理由を表示した入力欄の値を変えたら、その理由を消す
  - すでにある商品で委託元名を付けたら、入力した預かり部数を `consignedStock` に入れる。委託元名を外したら、その商品の項目を `consignedStock` から除き、`plannedStock` を 0 にする。どちらの場合も `openingStock` は変えない
  - おしながきから外した商品は、`plannedStock` と `consignedStock` からも消す
  - 商品マスタが読めないときは、前日準備と同じアラートを、ダイアログの本文の先頭に表示する（[前日準備.md](前日準備.md) の「画面」）
- 商品マスタへの新しい商品の登録
  - 商品マスタの画面と同じく、ISDN から登録するか、ISDN を持たない商品を入力して登録する（[../商品マスタ.md](../商品マスタ.md) の「商品の登録」）。ISDN からの登録はオンラインでだけ使える
  - 登録したら、おしながきに足せるようにする
  - 登録の「追加」のボタンは secondary にする。このダイアログの主要な操作は下部の「保存」なので、primary を 1 つにするため
