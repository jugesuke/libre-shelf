# 前日準備

おしながき（そのイベントで頒布する商品と価格）を登録する。

## 前提

- 頒布する商品を、商品マスタ（[../商品マスタ.md](../商品マスタ.md)）に登録してある

## 入力

| 項目 | 型 | 必須 | 内容 |
|---|---|---|---|
| イベント | テキスト | ○ | 即売会の名前（例: コミックマーケット107）。前後の空白は除いて記録する。空白だけなら入力していないものとする |
| 開催日 | 日付 | ○ | 既定値は、端末のタイムゾーンでの今日 |
| 商品 | 追加する一覧 | ○ | バーコードを読むか、プルダウンで商品マスタから選んで足す |
| イベントでの頒布価格 | 数値 | ○ | このイベントでの価格。0 以上の整数。足したときの既定値は商品マスタの `price`（標準の価格）で、なければ 0。空欄にしたら 0 として扱う |
| 委託元名 | テキスト | - | 委託物のときだけ入力する。入力しないか、空白だけなら、自サークルの頒布物になる |
| 持ち込み予定数 | 数値 | 自サークルの頒布物は ○ | 会場へ持ち込む予定の数。委託元名を入力していない商品では 0 以上の整数が必須 |
| 預かり部数 | 数値 | 委託物は ○ | 受け取ったときに数えた数。委託元名を入力した商品では 1 以上の整数が必須 |

持ち込み予定数と預かり部数は、どちらも当日開始処理での持ち込み数の基準になる（[index.md](index.md) の「持ち込み数の基準」）。

## 画面

- 足した商品だけを一覧に表示する。各行に、価格、委託元名、数の入力欄と、削除のボタンを置く
- 一覧の表の、数の入力欄の列の見出しは、どの行でも同じ「持ち込み予定数・預かり部数」とする。数の入力欄は 1 つで、委託元名を入力していない行では持ち込み予定数、入力した行では預かり部数として使う。委託元名が空から空でない値に、または空でない値から空に変わったら、数の入力欄を空にする
- 商品はバーコードを読む（13 桁のコードを入力して Enter）か、プルダウンで商品名から選んで足す。バーコードはバーコードリーダーのほか、端末のカメラでも読める（[../バーコードのカメラ読み取り.md](../バーコードのカメラ読み取り.md)）
- 読んだコード（13 桁でないものも含む）の商品が商品マスタになければ、足さずに「この商品は登録されていません。」と、足してあれば「すでに追加されています。」と表示する
- 足した商品はプルダウンの選択肢から除く
- 商品マスタが読めないとき（[../商品マスタ.md](../商品マスタ.md) の「データ」）は、商品を足せないので、おしながきの見出しの下に destructive のアラートで「登録した商品を読み込めないため、商品を追加できません。「商品管理」の画面で確かめてください。」と表示する
- イベントでの頒布価格を変えても、商品マスタの `price` は変えない

## 保存と遷移

- 「続きはあとで」ボタンで、入力をセッションに保存し、前日準備の画面のままにする。保存したら「保存しました。」と表示する
- 「レジへ進む」ボタンで、入力をセッションに保存して当日開始処理（`phase = opening`）に進む
- どちらのボタンも、次のときは保存せず、理由を表示する。商品ごとの理由は、その商品の行の入力欄の下に、商品が 1 つもないときの理由は「商品を追加」の欄の下に、それ以外は対応する入力欄の下に表示する
  - イベントを入力していない: 「イベントの名前を入力してください。」
  - 開催日を入力していない: 「開催日を入力してください。」
  - 頒布価格が 0 以上の整数でない: 「頒布価格を入力してください（0以上の整数）。」
  - 商品が 1 つもない: 「商品を1つ以上追加してください。」
  - 自サークルの頒布物の持ち込み予定数が 0 以上の整数でない: 「持ち込み予定数を入力してください（0以上の整数）。」
  - 委託物の預かり部数が 1 以上の整数でない: 「預かり部数を入力してください（1以上の整数）。」
- 理由を表示した入力欄の値を変えたら、値が正しいかによらず、その理由を消す。商品が 1 つもないときの理由は、商品を足したときに消す。商品の行を削除したら、その行の理由も消す
- 理由はすべて同時に表示する

## 出力

ここでいうセッションは、端末の localStorage に持つ即売会 1 日分のデータである（[セッションのデータ.md](セッションのデータ.md)）。前日準備の画面を開き直したときは、保存した値を入力欄に表示する。


- セッションの `eventName` と `eventDate` を記録する
- セッションの `menu` に、商品ごとの `itemId`、`price`、`consignorName` を記録する
- 自サークルの頒布物の持ち込み予定数を `plannedStock` に、委託物の預かり部数を `consignedStock` に、商品ごとに記録する

## まだ決まっていないこと

- 委託物かどうかを商品マスタでも持つか
