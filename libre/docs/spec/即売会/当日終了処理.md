# 当日終了処理

販売を終えてから撤収するまでに、会場で在庫とレジ金を数え、記録から求めた値と突き合わせる。手順に沿って進む画面（ウィザード）である。

画面に「レジに戻る」ボタンを置き、レジ（`phase = register`）に戻れるようにする。この遷移も localStorage に保存する。

## 手順 1: 残った在庫の数

- 商品ごとに、卓上に残っている数を数えて入力する（`closingStock`）
- 入力した数を、理論在庫と比べる

```
理論在庫(X) = 持ち込んだ在庫の数(X) − 販売数(X) − 見本誌の提出数(X) − 展示見本の数(X)
```

持ち込んだ在庫の数は `openingStock`、見本誌の提出数は `sampleSubmissions`、展示見本の数は `displaySamples` の値を使う。販売数は取り消していないトランザクションの数量の合計である。

## 手順 2: 終了時のレジ金

- 会場で回収した現金を数え、[当日開始処理.md](当日開始処理.md) の「レジ金の入力」で入力する（`closingCash`）
- 入力欄の金種の各行に、記録から求めた枚数と差（数えた枚数 − 記録から求めた枚数）の列を足して表示する。別の表は置かない。計算は [お釣りの振り返り.md](お釣りの振り返り.md) の「3. 終了時の枚数の突き合わせ」による。入力するたびに更新する

```
                                   記録        差
── 硬貨 ──────────────────────────────────────────────
  500円 × [ 枚数 ] 枚 = X,XXX円    N 枚        ±N
  100円 × [ 枚数 ] 枚 = X,XXX円    N 枚        ±N
── 紙幣 ──────────────────────────────────────────────
10,000円 × [ 枚数 ] 枚 = X,XXX円    N 枚        ±N
  …
── その他 ────────────────────────────────────────────
        [  金額  ] 円   X,XXX円
──────────────────────────────────────────────────────
                   合計 X,XXX円
```

  - 表の 1 行目を見出しの行にし、記録と差の列の上に「記録」「差」と書く。入力欄の列の上には見出しを書かない。各行には、記録は「N 枚」、差は数だけを書き、「記録」「差」の語は繰り返さない
  - 記録の枚数は、終了時のレジ金をまだ入力していなくても表示する。そのときの差は、入力していない欄を 0 枚として計算する。この画面では、お釣りの振り返り.md の「値がないとき」の「終了時のレジ金がなければ 3 は「—」」は当てはめない
  - 記録の枚数は、負の数になってもそのまま表示する（例: -1 枚）
  - 差は、正の数に「+」を付け、0 は「±0」と表示する
  - 開始時のレジ金がなければ、記録と差の列は「—」にする
  - 差が 0 でない行は、行の背景に色を付け、差の数字も目立つ色にする。文言は添えない
  - その他の行には、記録と差の列を置かない
  - 記録と差の列は右揃えにする
- 差があっても、次の手順に進める。この差は手順 4 の「差に応じた処理」の判定に使わない

## 手順 3: 差の表示

| 項目 | 式 |
|---|---|
| 在庫の差（`stockDifference`） | 残った在庫の数 − 理論在庫 |
| レジ金の差（`cashDifference`） | （終了時のレジ金 − 開始時のレジ金 − レジ金の出し入れの合計）− 販売の合計 |

レジ金とレジ金の出し入れは、合計の金額で計算する（[セッションのデータ.md](セッションのデータ.md)）。

差は、入力するたびに計算し直して表示する。

- レジ金の差は、終了時のレジ金の入力欄の下に「レジ金差異：」に続けて表示する。0 なら「±0（一致）」、正なら「+¥1,000（過剰）」、負なら「-¥1,000（不足）」の形にする（金額の書き方は [../デザイン/index.md](../デザイン/index.md) の「文言と書式」）
- 在庫の差は、「差異確認」の区画に表示する。差がなければ「在庫差異はありません。」と表示する。差があれば、見出し「在庫差異があります」、差が 0 でない商品ごとの差（「商品名：+1 部」の形）、「帰着後に原因を調査して修正してください。」を表示する

## 手順 4: 差に応じた処理

どの場合も、差をセッションの `stockDifference` と `cashDifference` に記録し、イベント終了（`phase = done`）に進む。

| 場合 | `stockDifference` |
|---|---|
| 在庫もレジ金も一致したとき | 空の配列 |
| 在庫に差があるとき（レジ金の差の有無によらない） | 差が 0 でない商品ごとの差 |
| レジ金にだけ差があるとき | 空の配列 |

- `cashDifference` には手順 3 のレジ金の差を記録する。一致したときは 0 である
- 在庫の差はイベント終了の画面で直してから確定する（[イベント終了.md](イベント終了.md)）
