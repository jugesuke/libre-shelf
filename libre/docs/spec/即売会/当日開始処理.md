# 当日開始処理

会場に着いてから販売を始めるまでに、レジ金、見本誌、持ち込んだ在庫を確かめて記録する。手順に沿って進む画面（ウィザード）で、一部の項目は飛ばせる。

## 入力

各項目は同じ画面で、行き来しながら入力できる。

| 項目 | 型 | 必須 | 飛ばせるか | 内容 |
|---|---|---|---|---|
| 開始時のレジ金 | 数値 | ○ | × | 釣り銭に用意した現金。下の「レジ金の入力」で入力する |
| 見本誌の提出数 | 商品ごとの表 | - | ○ | 準備会に提出する数 |
| 展示見本の数 | 商品ごとの表 | - | ○ | 卓上に置く見本の数 |
| 持ち込んだ在庫の数 | 商品ごとの表 | - | ○ | 実際に数えた、持ち込んだ数 |

画面の中のタブや区画を切り替えても、入力した値を消さない。

見本誌の提出数、展示見本の数、持ち込んだ在庫の数は、1 以上の整数だけを記録する。それ以外の値は、入力していないものとして扱う。開始時のレジ金を入力せずに終えようとしたら、進まずに「開始時レジ金を入力してください。」

## 処理

持ち込んだ在庫の表の上に、次の文言を 1 回表示する。文言の「持込部数」は、下の持ち込み数の基準のことである。「実際に持ってきた冊数を入力してください。持込部数（自サークル物は持ち込み予定数、委託物は預かり部数）と照合します。持込部数はその場で修正できます。」

展示見本の表の上には、次の説明を 1 回表示する。「卓上に置く見本分。入力しない場合は0のままで構いません。」と表示する。

1. 持ち込んだ在庫の数を入力したら、持ち込み数の基準との差を表示する
   - 基準は自サークルの頒布物では持ち込み予定数（`plannedStock`）、委託物では預かり部数（`consignedStock`）である（[index.md](index.md) の「持ち込み数の基準」）
   - 基準はこの画面で直せる。直した基準は前日準備と同じ規則で確かめ（自サークルの頒布物は 0 以上の整数、委託物は 1 以上の整数）、合わなければ保存せずに、前日準備と同じ文言を入力欄の下に表示する
   - 表の行ごとに、持ち込んだ在庫の数と基準との差を表示する
   - 差があれば、基準を直すことも、そのまま続けることもできる。あとからレジの「商品・価格編集」か、イベント終了の画面で直すこともできる
2. 見本誌の提出数と展示見本の数は、入力した時刻と一緒に localStorage に保存する
3. 終えたら、レジ（`phase = register`）に進む

## 飛ばす操作と、あとからの編集

- 「スキップしてレジへ進む」ボタンを置く。押したら、入力した値を保存せずにレジ（`phase = register`）に進む
- レジの画面に「開始処理を編集」ボタンを置く。押したらダイアログを開き、開始時のレジ金、見本誌の提出数、展示見本の数、持ち込んだ在庫の確認を入力し直せる。`phase` は `register` のまま変えない

## 出力

- `openingCash`、`openingStock`、`plannedStock`、`consignedStock`、`sampleSubmissions`、`displaySamples` を記録する（[セッションのデータ.md](セッションのデータ.md)）

## レジ金の入力

開始時のレジ金、終了時のレジ金（[当日終了処理.md](当日終了処理.md)）、レジの「開始処理を編集」の開始時のレジ金、イベント終了の画面の開始時と終了時のレジ金で、同じ入力欄を使う。金種ごとの枚数を入力すると、合計を計算する。

```
── 硬貨 ──────────────────────────────
  500円 × [ 枚数 ] 枚 = X,XXX円
  100円 × [ 枚数 ] 枚 = X,XXX円
── 紙幣 ──────────────────────────────
10,000円 × [ 枚数 ] 枚 = X,XXX円
 5,000円 × [ 枚数 ] 枚 = X,XXX円
 2,000円 × [ 枚数 ] 枚 = X,XXX円
 1,000円 × [ 枚数 ] 枚 = X,XXX円
── その他 ────────────────────────────
        [  金額  ] 円   X,XXX円
──────────────────────────────────────
                   合計 X,XXX円
```

- 硬貨、紙幣の順に、見出しを付けて並べる
- 「枚 =」「円」「合計」の左端を揃える
- その他の入力欄は金種の列まで含めた幅の分、左に余白を空けて置く
- 小計と合計は、右端の列に右揃えで表示し、入力するたびに更新する
- 小計と合計の金額は、金種と同じく「1,500円」のように後ろに「円」を付けて書く。「¥」は付けない
- 金種も金額も、1,000 以上は 3 桁ごとにカンマを入れる（例: 10,000円）
- その他には 1 円、5 円、10 円、50 円の硬貨の合計の金額を入力する
- 枚数とその他の金額はブラウザの数値入力（`input type="number"`）で入力する

合計 = Σ（金種 × 枚数）+ その他

- 金種ごとの枚数とその他の金額を、`openingCash` か `closingCash`（`CashCount | null`、[セッションのデータ.md](セッションのデータ.md)）に保存する。入力していない欄と、0 以上の整数でない値（負の数、小数など）を入れた欄は 0 とする
- 合計が 0 円なら、入力していない（`null`）ものとして扱う
- 保存した値があれば、開いたときに金種ごとの枚数とその他の金額を、それぞれの欄に表示する
- 当日終了処理では、金種の各行に、記録から求めた枚数と差の列を足して使う（[当日終了処理.md](当日終了処理.md) の「手順 2: 終了時のレジ金」）
