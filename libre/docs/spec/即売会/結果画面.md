# 結果画面

履歴に保存した過去のセッションの結果を表示する画面である。パスは `/event/result/:id` で、`:id` は履歴の `id` である（[セッションの保存.md](セッションの保存.md)）。

## 入力

- セッションの履歴のうち、`id` がパスと一致する 1 件
- 商品名とサークル名は、セッションのおしながきに写した値から出す（[セッションのデータ.md](セッションのデータ.md) の `MenuEntry`）。商品マスタは読まない
- サーバの API は使わない

## 表示

- 外枠には見出しに即売会の名前（`session.eventName`）、その下に開催日（`session.eventDate`）、右上に「一覧に戻る」「ファイルに書き出す」「削除」のボタンをこの順に置き、ボタンの間は 12px 空ける。「一覧に戻る」は `/event` へ移る。「ファイルに書き出す」はこのセッションをファイルとしてダウンロードさせる（[セッションの保存.md](セッションの保存.md) の「ファイルへの書き出し」）。「削除」は destructive のボタンで、この記録を履歴から消す（同じく「履歴から消す」）
- `id` が履歴にないときは、「指定したイベントの記録が見つかりません。「一覧に戻る」から一覧に戻れます。」と表示する。外枠の見出しは「イベント結果」にし、「ファイルに書き出す」と「削除」のボタンは置かない
- 本体には次の項目を順に表示する
  - [集計画面.md](集計画面.md) の項目
  - 自サークル分と委託分の売上の内訳と、委託販売のサマリー（[イベント終了.md](イベント終了.md) の委託タブと同じもの。コピーの機能も含む）
  - お釣りの振り返り（下の「お釣りの振り返りの表示」）
- `session.schemaVersion` が今のスキーマ（[セッションのデータ.md](セッションのデータ.md)）と違うときは、本体の代わりに「対応していないスキーマバージョンです。（バージョン）」と表示する

### お釣りの振り返りの表示

[お釣りの振り返り.md](お釣りの振り返り.md) の計算の結果のうち、次の問いに答えるものだけを、下の「結論」「金種ごとのまとめ」「記録と合わなかった金種」の順に表示する。委託販売のサマリーのあとに置く。以下、「計算の 1」などは、お釣りの振り返り.md の出力の番号を指す。

- 今回、お釣りは足りたか
- 金種ごとに、用意した枚数、お客さんから受け取った枚数、お釣りに出た枚数、両替なしで必要だった枚数
- その結果は記録と合っているか

計算の 2 のいちばん少なくなったときの枚数と時刻、レジ金の出し入れの一覧は、結果画面には出さない。どれもセッションの JSON に残るので、詳しく見るときは JSON を別に処理する。

#### 結論

- 計算の 2 の 0 枚を下回った最初の時刻がある金種ごとに、「5,000円が 10:30 に足りなくなりました」と 1 行で書く。時刻（ms）の早い順に並べ、同じ時刻なら金種の小さい順にする
- 下回った金種がなければ「お釣りは足りました」と書く
- 開始時のレジ金がなければ「開始時のレジ金がないため、足りたかは分かりません」と書く

#### 金種ごとのまとめ

金種を行、次の列を左から並べた表にする。金種は 100円から 10,000円へ小さい順に並べる。

| 列の見出し | 値 |
|---|---|
| 金種 | 「1,000円」の形 |
| 用意した | 開始時のレジ金の枚数 |
| 受け取った | 計算の 5 の受け取った枚数 |
| お釣りに出た | 計算の 4 のお釣りに出た枚数 |
| 必要だった枚数 | 計算の 1 の両替なしで必要だった枚数 |

- 値がない（「—」）ときの扱いは、お釣りの振り返り.md の「値がないとき」による。用意したは、開始時のレジ金がなければ「—」にする
- 表の上に、「お釣りは、足りるときは最少枚数で渡したとして計算しています」と添える
- 計算の 3 の差が 0 でない金種の行は、行の背景に色を付ける。色は当日終了処理の入力欄と同じにする。差がない（「—」の）行には色を付けない
- 表の見出しとセルは折り返さない。画面の幅に収まらないときは、表だけを横にスクロールさせる

#### 記録と合わなかった金種

- 計算の 3 の差が 0 でない金種があるときだけ、表の下に出す。差がない（「—」の）金種は数えない
- 金種ごとに「500円: 記録 2 枚、数えた 0 枚」と 1 行で書く。記録は計算の 3 の記録から求めた枚数、数えたは終了時のレジ金の枚数
- その下に「色の付いた行は、足りたかと必要だった枚数が不正確なことがあります。」と添える

時刻は端末のタイムゾーンの `HH:mm` で表示する。
