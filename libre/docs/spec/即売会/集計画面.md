# 集計画面

開催中に、売上の状況を確かめる画面である。レジの「集計確認」ボタンでダイアログとして開く（[レジ.md](レジ.md)）。

## 入力

- localStorage にあるセッションのトランザクション（取り消したものを除く）とおしながき。API は使わない

## 表示

| 項目 | 内容 |
|---|---|
| 総売上 | 販売金額の合計 |
| 商品ごとの売上高 | 商品ごとの販売金額 |
| 商品ごとの売上冊数 | 商品ごとの販売数 |
| 時間ごとの頒布冊数（合計） | 30 分ごとの販売数 |
| 時間ごとの頒布冊数（商品ごと） | 商品ごと、30 分ごとの販売数 |
| 知り合いと知り合い以外の内訳 | 購入者の区分ごとの集計 |
| 自サークル分と委託分の内訳 | 総売上の内訳。委託物の売上があるときだけ表示する。商品ごとの一覧では、委託物に委託元名を添える |

## まだ決まっていないこと

- 自サークル分と委託分の内訳を、開催中の画面に残すか
