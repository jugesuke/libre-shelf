# Card

カードは、関係する内容をまとめて囲むコンポーネントです。ヘッダーに見出しと操作を置けます。

<Canvas of={CardStories.All} />

## ヘッダー

- 見出しがあるときは、上にグレーの背景のヘッダーを付ける。見出しがないときは、ヘッダーを付けず中身を囲む。
- 見出しに補足を付けるときは、見出しの右に 12px 空けて、補足のテキストの大きさと色で置く。
- ヘッダーの右にはそのカードに対する操作を置ける。
- ヘッダーの高さは最低 48px。ボタンを置いても 48px のまま。画面幅が 640px 未満のときは、操作を 2 行目に置く。

## 折りたためるカード

普段は使わない入力欄など、必要なときだけ開けばよい内容に使います。ヘッダーの左の矢印と見出しをクリックすると開閉します。

<Canvas of={CardStories.CollapsibleWithActions} />

- 閉じているときは右向き、開いているときは下向きの矢印
- 操作はクリックしても開閉しない。

## 無効状態

前の操作を済ませるまで使えないカード（商品を選ぶまでの「新規移動を登録」など）は、中身を操作できないようにし、全体を薄く表示します。

## アクセシビリティ

- 折りたためるカードの開閉のボタンは見出しの文字がそのまま名前になり、開閉の状態も読み上げられる。

## チェックリスト

- [ ] 開閉する箇所には折りたためるカードを使っている。
- [ ] ヘッダーの操作はそのカードに対するものだけにしている。

## 実装

- `title` に見出し、`description` に補足、`actions` にヘッダーの右に置く要素を渡す
- 折りたためるカードは `collapsible`、`open`、`onOpenChange` を指定する。開いているかは使う画面が持つ。
- 無効状態はカードに `inert` と `className="opacity-40"` を付ける。
- `className` と HTML の属性はカードの外側の要素に渡る。
- `actions` と `description` は、`title` があるときだけ表示する。折りたためるカードでは `title` が必須。

### 寸法と色

- 白い背景に、1px の `--border` の枠線。中身の内側の余白は 16px。
- ヘッダーは `--surface-muted` の背景、16px の太字、下に 1px の `--border` の線。
- ヘッダーの高さは最低 48px で、内側の余白は上下 4px、左右 16px。中身は上下の中央に置く。
- 見出しと操作の間は 16px。見出しと操作が 1 行に収まらないときは、操作を次の行に左寄せで回し、行の間を 8px 空ける。画面幅が 640px 未満のときは、常に次の行に回す。
- 補足は 12px の標準の `--muted-foreground`。見出しの最後の行に 12px 空けて続け、入りきらないときは次の行から始める。
- 折りたためるカードの開閉のボタンは見出しと矢印をまとめた 1 つのボタンで、`aria-expanded` で開いているかを示す。高さは最低 36px、左右の内側の余白は 8px（ヘッダーの左の余白も 8px にし、矢印の左端を中身の左端にそろえる）。矢印と見出しの間は 8px。
- 矢印は lucide-react の `ChevronRight`（閉じているとき）と `ChevronDown`（開いているとき）。20px 四方、`--muted-foreground`。
- 開閉のボタンはホバー時と押している間に `--muted` の背景を敷く。
- 閉じているときは中身を表示せず、ヘッダーの下の線も出さない。
