# Dialog

ダイアログは、画面の上に重ねて表示し、確認、フォームの入力、詳細の表示などに使うコンポーネントです。開いている間は、後ろの画面を操作できません。

<Canvas of={DialogStories.Confirm} />

## 種類と使い分け

| 幅 | 最大幅 | 用途 |
|---|---|---|
| sm | 448px | 確認や、短いフォーム |
| md | 672px | 長いフォームや、詳細の表示 |
| lg | 896px | 列の多いテーブルを含む詳細の表示（発注の詳細の入荷履歴など） |

<Canvas of={DialogStories.LongForm} />

## 配置

- 右上に閉じるボタン、左上に見出しを置く。
- 下部のボタンは横幅いっぱいに等分して並べ、左に「キャンセル」などの secondary、右に主要な操作（primary か destructive）を置く。ボタンが 1 つのときは横幅いっぱいにする。
- 画面幅が 640px 未満のときは、ボタンを縦に並べ、主要な操作を上にする。
- 画面の高さが足りないときは、ダイアログの中でスクロールする。

## 操作

- Esc キー、閉じるボタン、背景のオーバーレイのクリックで閉じる。
- 閉じたら、ダイアログを開いたボタンにフォーカスを戻す。

## 処理の失敗

処理に失敗したら、ダイアログを開いたまま、下部のボタンの行の下にアラートを浮かせて出します。ダイアログの枠の外へはみ出させ、本文の入力欄を隠しません。出し方は[フィードバック](?path=/docs/デザインパターン-フィードバック--docs)の「処理の失敗」に従います。

<Canvas of={DialogStories.WithFailure} />

## 本文が長いとき

本文をスクロールさせ、見出しと下部のボタンは動かしません。

<Canvas of={DialogStories.ScrollingBody} />

## 最初のフォーカス

ダイアログを開いたときに最初にフォーカスを置く場所は、ダイアログの種類で決めます。

| 種類 | 例 | 最初のフォーカス |
|---|---|---|
| [確認](?path=/docs/デザインパターン-確認--docs)（元に戻せない操作） | 削除、取り消し、破棄 | 「やめる」 |
| フォーム | 発注の登録、ロケーションの追加 | 最初の入力欄 |
| 詳細の表示（テーブルや、項目と値が並ぶ詳細） | 発注の詳細、会計一覧、商品の詳細 | 見出し |
| ボタンが 1 つの通知 | 登録が完了したことの通知 | そのボタン |

### なぜ見出しに置くことがあるのか

画面が見える人は、詳細のダイアログを開くと見出しから順に中身を見ます。最初の操作できる要素に置くと、スクリーンリーダーを使う人は中身を飛ばしてボタンから読むことになり、同じ順に読めません。中身が長いと、先頭が画面の外にスクロールすることもあります。

## アクセシビリティ

- 開いている間は、フォーカスをダイアログの中に閉じ込める。

## チェックリスト

- [ ] 主要な操作を右（狭い画面では上）に置いている。
- [ ] 取り消せない操作の確認では、主要な操作を destructive にしている。

## 実装

- `open` と `onOpenChange` で開閉を管理し、`title` に見出し、`size` に `sm`（省略時）、`md`、`lg` のどれか、`footer` に下部のボタンを渡す
- 処理の失敗は `failure` に文言を渡す。下部のボタンの行の下に、行と同じ幅の destructive のアラート（`FloatingAlertBody`。行の下端と三角の先の間は 4px）を浮かせて重ね、ダイアログの下の余白に重ねて枠の外へはみ出させる。三角は下部の最後のボタン（主要な操作）の左右の中央に向ける。閉じるボタンか Esc キーで `onFailureClose` を呼ぶ。Esc キーは、アラートが出ている間はアラートを閉じ、ダイアログは閉じない。アラートは `body` の直下ではなく、ダイアログの中の要素として、下部のボタンの行を基準に描く。Tab キーで閉じるボタンに届くようにするため。`footer` がないときは出さない。
- Radix UI の Dialog（`@radix-ui/react-dialog`）を使っている。最初のフォーカスは Radix の `onOpenAutoFocus` で指定する。見出しに置くときは、見出しに `tabindex="-1"` を付ける。見出しは操作する要素ではないので、フォーカスしても枠は出さない。指定は `initialFocus` で、`"content"`（既定。中身の最初のフォーカスできる要素、なければ下部のボタン）、`"title"`（見出し）、要素の ref のどれか。

### 寸法と色

- オーバーレイは `--overlay`（#101828 の 50%）。ぼかさない。
- 内側の余白は 24px。画面の幅が足りないときは、左右に 16px 空けて縮める。
- 見出しは 18px の太字。見出しと中身の間は 16px、中身と下部のボタンの間は 24px。
- 閉じるボタンは icon のボタンで、記号は `X`、`aria-label` は「閉じる」。ダイアログの右上から 16px の位置に置き、見出しと重ねない。
- 下部のボタンの間は 12px。ボタンの文字は折り返さない。
- 画面の縦が足りないときは、上下に 16px 空けて、ダイアログの中でスクロールする。スクロールするのは本文で、見出しと下部のボタンは動かさない。本文のスクロールする部分は、入力欄のフォーカスリング（外側に 2px 離して 2px）が切れないよう、内側に 4px の余白を取る。
- ダイアログの外枠は、はみ出しを隠さない。下部のボタンの下に出す失敗のアラートを、枠の外へはみ出させるため。
