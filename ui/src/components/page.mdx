# Page

ページは、画面の本文を包み、ページの幅、外側の余白、ページの見出しを決めるコンポーネントです。プライマリカラーを持つ画面では、本文はこのコンポーネントの中に置きます。

<Canvas of={PageStories.Default} />

## 種類と使い分け

| 種類 | 最大幅 | 用途 |
|---|---|---|
| wide | 1200px | 一覧やテーブルが中心の画面 |
| narrow | 672px | フォームが中心の画面 |

どの画面がどちらを使うかは、[レイアウト](?path=/docs/基本デザイン-レイアウト--docs)のページにあります。

## 配置

- 左にページの見出し、右にその画面全体に対する操作（「新規ロケーションを追加」「セッションを破棄する」など）を置く。
- 画面幅が 768px 未満のときは、操作を見出しの下に回し、左に寄せる。
- 外側の余白は、画面幅が 768px 未満で 12px、768px 以上で 24px。

## チェックリスト

- [ ] 画面に合った幅（wide か narrow）を選んでいる。
- [ ] 画面全体に対する操作だけを見出しの右に置いている。

## 実装

- `title` に見出し、`actions` に見出しの右に置く要素、`width` に `wide`（省略時）か `narrow` を指定する
- `Page` は [`Frame`](?path=/docs/ui-frame--docs)の本文の中に置く。`Frame` は、プライマリカラーを持つ画面の本文には幅と余白を付けず、`Page` に任せる。プライマリカラーを持たない画面には、`Frame` が最大 1200px の幅と 12px の余白を付ける。

### 寸法

- 最大幅は外側の余白を含めた幅。中央に寄せる。
- 見出しは 24px の太字。画面幅が 768px 以上では、操作を見出しと縦の中央でそろえる。
- 見出しと操作の間は 12px、見出しの行と本文の間は 16px。
