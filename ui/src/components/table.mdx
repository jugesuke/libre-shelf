# Table

テーブルは、一覧を行と列で示すコンポーネントです。

<Canvas of={TableStories.All} />

## デザイン

- テーブルは枠線で囲み、ヘッダー行はグレーの背景に太字の補足のテキストの色。
- セルの内側の余白は上下 8px、左右 12px。
- 数量と金額の列は右に寄せ、桁をそろえる。商品 ID のような番号は数量に含めず、左に寄せる。
- 文字は折り返さない。テーブルが画面に入りきらないときは、テーブルの中で横にスクロールする。コメントや場所の名前のように、利用者が自由に書く長い文字の列は、2 行まで折り返し、それ以降は末尾を「…」で省く。

## クリックできる行

クリックすると詳細などが開く行は、ホバー時と押下時に薄いグレーの背景色を付け、ポインターを指の形にします。クリックできない行はホバーしても変えません。

<Canvas of={TableStories.WithRows} />

## 行がないとき

行が 1 つもないときは、1 行を使って、何がないかと、どうすれば表示されるかを中央に書きます。行にボタンや入力欄があるテーブルでは、この 1 行の高さを、ボタンのある行と同じにします。

<Canvas of={TableStories.Empty} />

## 読み込み中

読み込み中は、テーブルの見出しの行を表示し、行がないときの 1 行と同じ場所の中央に、ローダーを出します。

## 読み込み直しているとき

表示しているテーブルを読み込み直している間は、前の中身を出したまま、見出しの行を除いた中身の行を薄くし（不透明度 40%）、操作できなくします。中身の行の範囲の中央に、フォーカスリングと同じ色（`--ring`）のローダーを重ねます。

どちらも見本は[読み込み中と処理中](?path=/docs/デザインパターン-読み込み中と処理中--docs)にあります。

## チェックリスト

- [ ] 数量と金額の列を右に寄せている。
- [ ] 行がないときの文言で、どうすれば表示されるかが分かる。

## 実装

- `Table`、`TableHeader`、`TableBody`、`TableRow`、`TableHead`、`TableCell`、`TableEmpty` を組み合わせる
- 数量と金額の列は、`TableHead` と `TableCell` に `numeric` を付ける。
- クリックできる行は `TableRow` に `interactive` を付ける。
- 行がないときは、`TableEmpty` の `colSpan` に列の数を指定する。行にボタンや入力欄があるテーブルでは `controlRows` を付ける。読み込み中も、`TableEmpty` の中にローダーを入れる。読み込み直しているときのローダーは、`TableEmpty` ではなく、中身の行の上に重ねる要素に入れる。

### 寸法と色

- 外枠は `--border`、行の区切りは `--border-muted` の 1px の線。
- 見出しの行は `--surface-muted` の背景に、14px の太字の `--muted-foreground`。
- クリックできる行はホバー時と押している間に `--muted` の背景を敷き、`cursor: pointer` にする。
- 行がないときの文言と、読み込み中のローダーは、14px の `--muted-foreground`。`controlRows` を付けた行は、ボタンのある行と同じ 52px の高さにする。
- 数量と金額は `tabular-nums` で桁をそろえる。
