# TextLink

テキストリンクは、別のページや同じページの別の場所へ移動するコンポーネントです。[リンクのルール](?path=/docs/基本デザイン-リンク--docs)に従って使います。

<Canvas of={TextLinkStories.All} />

## 用途

- 本文中のリンクと、単独で置くテキストリンクに使う。
- 操作を実行するときは[ボタン](?path=/docs/ui-button--docs)を使う。

## デザイン

- 本文中でも単独で置く場合でも、青い文字と常時表示する下線で示す。訪問済みは紫にする。
- 文字の大きさ、太さ、行送りは、周囲の文字とそろえる。
- 長い URL は表示幅に合わせて折り返す。新規タブの記号は、リンクの末尾の文字と一緒に折り返す。

<Canvas of={TextLinkStories.InText} />
<Canvas of={TextLinkStories.LongUrl} />

## 開き方

外部リンクは、原則として新規タブで開きます。内部リンクでも、元の画面を残して別のページを参照する必要があるときは新規タブを使います（[リンクのルール](?path=/docs/基本デザイン-リンク--docs)）。

新規タブで開くリンクには、文言の末尾に記号を付けます。同じタブで開くリンクには付けません。

<Canvas of={TextLinkStories.NewTab} />

## 状態

| 状態 | デザイン |
|---|---|
| 未訪問 | 青い文字と下線 |
| 訪問済み | 紫の文字と下線 |
| ホバー時 | 少し暗くし、下線を太くする |
| 押下時 | ホバー時より暗くする |
| フォーカス時 | プライマリカラー（黄は黒）の 2px のフォーカスリング |

## アクセシビリティ

- 新規タブの場合は、読み上げ用の説明「新しいタブで開きます」を付ける。
- 記号はリンクの文言と一緒にクリックできるようにする。
- 単独で置くリンクは、上下に余白を取り、クリックできる領域の高さを 32px 以上にする。文章の中のリンクは、周囲の行送りに合わせる（[ターゲットサイズ](?path=/docs/基本デザイン-ターゲットサイズ--docs)）。

## 実装

- `children` に文言の文字列、`href` に移動先の URL を渡す。
- 開き方は `target` で指定する。省略時と `_self` は同じタブ、`_blank` は新規タブ。
- 新規タブの場合は、記号と読み上げ用の説明を付け、`rel` に `noopener noreferrer` を加える。渡された `rel` の値は残す。文言を `aria-label` で指定した場合も、新規タブで開く説明を加える。

### 寸法と色

- 未訪問は `--link`、訪問済みは `--link-visited` の文字。下線は 1px で、文字から 3px 離す。
- 新規タブの記号は lucide-react の `ExternalLink`、12px。記号の前は 2px、後ろは 4px 空ける。記号には下線を付けない。
- ホバー時は `brightness(0.92)`、押下時は `brightness(0.85)`。ホバー時の下線は 2px。
- フォーカス時は、2px の `--ring` の輪郭を外側に 2px 離して表示する（`:focus-visible`）。
