# 色

Shelf で使う色はプライマリカラー、セマンティックカラー、グレーの 3 種類です。この 3 種類にない色は使いません。

## プライマリカラー

プライマリカラー（`--primary`）は、その画面の主要な操作に使う色です。値は画面ごとに変え、いまどの画面にいるかの目印にもします。プライマリカラーは次の色の一覧から選び、どの画面にどの色を使うかは、アプリが決めます。

<PaletteTable />

使用箇所は次のとおりです。

- メニューで選択中の項目と、画面上端の帯
- primary のボタンの背景色
- セグメントコントロールの選択中の項目の背景色と、タブの選択中の項目の下線
- 白い背景に置く大きな数字（即売会のレジの合計金額など）。黄は白い背景とのコントラストが低いので、文字には使わない。

上記以外にはプライマリカラーを使いません。ほかの箇所にも使うと、目印として目立たなくなるためです。

### 黄のタブの下線とフォーカスリング

黄では、タブの選択中の項目の下線と、フォーカスリングを黒にしています。選択状態のインジケーターとフォーカスリングは、白い背景とのコントラスト比が 3:1 以上必要ですが、黄は 1.57:1 しかないためです。

アラートはセマンティックカラーを薄くした背景色に、同じセマンティックカラーの文字を置きます。ただし destructive のアラートの文字は、`--destructive`（#e7000b）より濃い `--destructive-muted-foreground`（#c10007）にします。`--destructive` では、薄くした背景色とのコントラスト比が 4.36:1 で、4.5:1 に届かないためです。destructive のボタンでの使い方は、[ボタン](?path=/docs/ui-button--docs)のページにあります。

## グレー

グレーは次の 8 段階を使います。

  ]}
/>

用途ごとの名前はどれかの段階を指します。

文字と入力欄の枠線には、白とのコントラスト比が 4.5:1 以上のグレー（gray-500 以上の濃さ）を使います。それより薄いグレーは、区切り線のように見分けに必要ない箇所と、無効状態の文字（`--disabled-foreground`）に使います。無効状態のコンポーネントは、コントラストの基準の対象にならないためです（[原則](?path=/docs/原則--docs)）。
