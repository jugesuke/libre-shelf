# コンセプト

Shelfは、同人活動における事務作業をシステムでサポートすることで、作品づくりに集中できる環境を目指します。
作品づくりに集中しながら、頒布の記録などから上がってくる様々なログを適切に整理し、作品づくりや見せ方に活かせるようにします。
作品づくりの障害をできるだけ減らすようなシステムを目指して、様々な工夫を行います。
デザインシステムは、それらを体現するような内容にします。

## わかりやすい

直感的に使えるようにします。
作品づくり・同人活動とは関係のない学習ができるだけ少なくなるようにします。

## たのしい

余暇活動である同人創作活動を妨げない、たのしいシステムを目指します。
表示はできるだけ平易かつ堅くない雰囲気にします。

## じゃましない

同人活動をじゃましないシステムづくりをします。
同人活動をさまたげるような面倒な作業はできるだけ避け、負担なく利用できるシステムを目指します。
頒布中などにログを集める場合は、できるだけ負担が増えない方法を取ります。
また、Shelfが原因で活動が止まることをできるだけ避けます。
障害となるポイントを分析して、可能な限りトラブルを避けられるようにします。
