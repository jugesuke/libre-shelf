# Shelf デザインシステム

Shelf は、個人で同人誌を頒布するサークルが、商品、在庫、即売会での販売を管理する Web アプリケーションです。
このデザインシステムは Shelf の画面を作るときに使うデザインのルールとコンポーネントをまとめたものです。新しい画面やコンポーネントを作るときは、ここに書いたルールに従います。

## 構成

| 項目 | 内容 |
|---|---|
| コンセプト | Shelf とこのデザインシステムが目指すもの |
| 原則 | コンセプトのもとで、画面を作るときに守るルール |
| 基本デザイン | 色、文字、余白、角丸、影、アニメーション、ターゲットサイズ、ページの幅とブレークポイント、文言と書式。すべてのコンポーネントが共通で使う値と、その使い方 |
| コンポーネント | ボタン、フィールド、カード、ダイアログなど。それぞれの用途、種類の使い分け、配置、状態、使用例 |
| デザインパターン | フィードバック、確認、読み込み中と処理中、何もないとき。複数の画面で繰り返し使う構成 |
| 開発 | 新しいコンポーネントを作る人向けの、色の変数とスタイルの指定方法 |
| 参考文献 | ルールを決めるときに参考にした資料 |

## 対象にしない画面と表示

- ダークモードは対象にしません。

## 用語

| 用語 | 意味 |
|---|---|
| プライマリカラー | 主要な操作に使う色（`--primary`）。即売会、商品管理などの画面ごとに値が変わる。[色](?path=/docs/基本デザイン-色--docs)のページに一覧がある |
| 主要な操作 | その画面でいちばん重要な操作。primary のボタンにする |
| 無効状態 | クリックや入力ができない状態 |
