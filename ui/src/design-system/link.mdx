# リンク

リンクは、別のページや同じページの別の場所へ移動するために使います。保存や削除など、その場で操作を実行するものには[ボタン](?path=/docs/ui-button--docs)を使います。

リンクには、リンク先が分かる文言を付けます。

## リンク先と開き方

外部リンクは、入力中の画面を残すため、原則として新規タブで開きます。内部リンクでも、元の画面を残して別のページを参照する必要がある場合は新規タブを使います。

## 記号の意味

四角い枠から右上へ矢印が伸びる記号は「新規タブで開く」を示します。内部・外部を問わず新規タブで開くリンクに付け、読み上げ用の説明を「新しいタブで開きます」にそろえます。同じタブで開くリンクには付けません。

## テキストリンクの見た目

テキストリンクは、本文中でも単独で置く場合でも、青い文字と常時表示する下線で示します。訪問済みは紫にし、下線は残します。色は画面によらず共通です。

テキストリンクには[TextLink](?path=/docs/ui-textlink--docs)を使います。開き方とその通知のルールは、すべてのリンクに適用します。

色は[色](?path=/docs/基本デザイン-色--docs)、間隔は[余白](?path=/docs/基本デザイン-余白--docs)、文字は[タイポグラフィ](?path=/docs/基本デザイン-タイポグラフィ--docs)に従います。
