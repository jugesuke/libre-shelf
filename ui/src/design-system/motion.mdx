# アニメーション

アニメーションは、状態が変わったことに気づいてもらう必要があるものに付けます。

| アニメーションを付けるもの | 動き |
|---|---|
| トーストの表示と消去 | 上から下へ移動しながら表示し、消すときは透明にしていく（sonner の既定） |
| ローダー | 回し続ける（`animate-spin`） |
| メニューの項目の色の切り替え | ホバーしたときの色を 0.15 秒で切り替える（`transition-colors`） |

ダイアログ、浮かせて重ねるアラート、メニュー、折りたためるカードの開閉には、アニメーションを付けません。すぐに表示し、すぐに消します。
