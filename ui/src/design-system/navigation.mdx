# Frame

フレームは、すべての画面の外側に置き、画面を切り替えるメニューと、画面の上端の帯を表示するコンポーネントです。

<Canvas of={FrameStories.Default} />

## 構成

| 部分 | 内容 |
|---|---|
| 上端のバー | 左から、メニューを開閉するボタン、アプリのアイコン、アプリの名前。画面の幅いっぱいに、常に表示する |
| メニュー | 上端のバーの下の左側の列。画面の項目をグループに分けて並べる。項目が 1 つのグループは見出しを出さない |
| 帯 | 本文の上端の細い帯。選択中の画面のプライマリカラーにする。メニューの上には出さない |
| 本文 | 帯の下。各画面は [Page](?path=/docs/ui-page--docs) を置く |

## 開閉

- 画面の幅が 768px 以上なら、メニューは本文を右へ押し出して表示する。
- 768px 未満なら、メニューは本文の上に重ねて表示し、上端のバーより下の本文を、ダイアログと同じオーバーレイ（`--overlay`）で隠す。
- 閉じているときは、メニューも覆いも表示しない。帯は開閉によらず表示する。

いつ開き、いつ閉じるかは、仕様の `docs/spec/ナビゲーション.md` の「開閉の状態」にあります。

## 色

| 部分 | 色 |
|---|---|
| 上端のバーとメニューの背景 | gray-900 |
| 上端のバーの文字 | 白 |
| メニューの項目の文字 | gray-300 |
| グループの見出し | gray-400 |
| 選択中の項目 | 角丸の背景を、その画面のプライマリカラーで塗る。文字は `--primary-foreground`（黄は黒、ほかは白）の太字 |
| ポインターを重ねた項目 | 角丸の背景に、その項目の画面のプライマリカラーを 25% の不透明度で重ねる。文字は白 |
| フォーカスリング | 白（`#ffffff`）の 2px。メニューの項目では、項目の縁に付けて外側に出す（離さない）。メニューを開閉するボタンでは、外側に 2px 離して出す |
| 帯 | 選択中の画面のプライマリカラー |

黄の上では白の文字が読めないので、選択中の項目の文字を黒にします。

<Canvas of={FrameStories.Yellow} />

## アクセシビリティ

- フォーカスリングは、メニューの背景（gray-900）の上に出るので、ほかのコンポーネントの `--ring` ではなく白にする。白と gray-900 のコントラスト比は 17.75:1。
- メニューを開閉するボタンの名前は、開いているときは「メニューを閉じる」、閉じているときは「メニューを開く」にし、`aria-expanded` で開いているかを示す。
- 選択中の項目に `aria-current="page"` を付ける。

## チェックリスト

- [ ] 色をグレーの段階、プライマリカラー、白から取っていて、Tailwind の標準の色を使っていない。
- [ ] 項目の高さが 32px 以上ある。
- [ ] キーボードで選んだ項目とボタンに、白のフォーカスリングが外側に出る。

## 実装

- `ui/src/frame/sidebar-frame.tsx` の `Frame`。各画面は `currentTab` に自分の画面のキーを渡して、本文を包む。
- メニューの項目（画面の名前、プライマリカラー、メニューの項目の色）は `pages` に、グループは `groups` に、上端のバーの題名は `title` に、アプリが渡す。プライマリカラーとメニューの項目の色は、`ui/src/palette.ts` の色の一覧から取る。
- プライマリカラー（`theme`）を持たない項目の画面では、`Frame` が本文に最大 1200px の幅と 12px の余白を付ける。
- `Frame` は選択中の画面のプライマリカラーを `html` 要素の `--primary`、`--primary-foreground`、`--ring` に設定する（[色の変数](?path=/docs/開発-色の変数--docs)）。

### 寸法

- 上端のバーの高さは 56px。アイコンは 36px 四方。
- メニューの幅は 224px。メニューの内側の余白は上下 4px、左右 8px で、項目はその内側に並べる。
- 項目は角丸（6px）。項目の内側の余白は上下 12px、左右 16px。
- 項目どうしの間は 8px 空ける。1 項目のグループが続く所（「即売会」と「商品管理」など）も同じにする。グループの見出しと、その下の項目の間は 4px。フォーカスリングは項目の外へ 2px 出るので、隣の項目との間に 6px が残り、リングが隣の項目に接しない。
- 帯の高さは 4px。

### 文字

[タイポグラフィ](?path=/docs/基本デザイン-タイポグラフィ--docs)のテキストスタイルを使う。

| 部分 | テキストスタイル |
|---|---|
| アプリの名前 | 見出し（中）（18px の太字） |
| メニューの項目 | 本文（14px の標準） |
| 選択中の項目 | 本文を太字にしたもの（14px の太字） |
| グループの見出し | 補足（12px の標準） |
