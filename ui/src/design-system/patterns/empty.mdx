# 何もないとき

一覧や集計に、出すものが 1 つもないときの見せ方です。

## 文言

何がないかと、どうすれば出るかを書きます。どうすれば出るかが分かりきっている箇所にも書きます。

終わった即売会の記録を見る画面のように、これから足すことができないものは、どうすれば出るかを書かず、何がなかったかを過去の形で書きます。ボタンの名前を書くときは、画面のボタンと同じ言葉にし、「」で囲みます。文なので、最後に句点（。）を付けます。

| 箇所 | 文言 |
|---|---|
| 発注一覧 | 発注がありません。「新規発注を登録」から登録できます。 |
| レジのカート | カートに商品がありません。バーコードを読み取るか、商品を選ぶと追加されます。 |
| 開催中の集計画面 | まだ会計記録がありません。レジで会計すると表示されます。 |
| 即売会の結果の画面（終わった即売会の記録） | 会計記録がありませんでした。 |

## テーブル

テーブルの見出しの行を表示し、テーブルの中の 1 行に、中央寄せで文言を書きます。テーブルを消して文言だけを出すことはしません。

<Canvas of={EmptyStories.EmptyTable} />

これから足すことのできない、終わった即売会の記録では、どうすれば出るかを書きません。

<Canvas of={EmptyStories.EmptyPastRecord} />

この 1 行は[テーブルの読み込み中](?path=/docs/デザインパターン-読み込み中と処理中--docs)にローダーを出す場所と同じです。

## カードの並び

在庫管理のロケーションの一覧のように、カードを並べる箇所では、カード 1 枚と同じ高さ（48px）の枠に、中央寄せで文言を書きます。

<Canvas of={EmptyStories.EmptyCardList} />

## 集計

総売上やグラフのように、データを集計して表示する箇所では、中身全体を文言に置き換えず、集計の形を残します。総売上のような数は 0 を出し、グラフの場所に文言を書きます。グラフの場所の高さはグラフと同じにします。
