# ターゲットサイズ

ボタン、セグメントコントロール、タブ、閉じるボタン、メニューの項目など、クリックやタップで操作する要素は、高さを 32px 以上にします。文章の中のリンクは対象にしません。

| 要素 | 高さ |
|---|---|
| ボタン、入力欄 | 36px |
| icon のボタン、セグメントコントロール | 32px |
| タブ | 36px |

### なぜ 32px なのか

WCAG 2.2 の AA が求めるのは 24px 以上です。ただ、24px のボタンを並べると、押し間違えないように間隔のルールが別に必要になります。32px 以上にすれば、間隔を気にせずに並べられます。
