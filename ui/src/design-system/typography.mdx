# タイポグラフィ

## フォント

フォントは [BIZ UDPゴシック](https://fonts.google.com/specimen/BIZ+UDPGothic)を使います。太さは標準（400）と太字（700）の 2 種類です。

## テキストスタイル

文字の大きさと太さは、次の 6 つのテキストスタイルから選びます。部品がテキストスタイルを持っているときは、部品のものを使います（ボタンのラベル、テーブルの見出しの行など）。

| テキストスタイル | 大きさ | 太さ | 使う箇所 | 例 |
|---|---|---|---|---|
| 見出し（大） | 24px | 太字 | ページの見出し | <span className="text-2xl font-bold">商品一覧</span> |
| 見出し（中） | 18px | 太字 | セクションの見出し、ダイアログの見出し | <span className="text-lg font-bold">開始時レジ金</span> |
| 見出し（小） | 16px | 太字 | カードの見出し | <span className="text-base font-bold">ISDN から商品を追加</span> |
| 本文 | 14px | 標準 | 文章、テーブルのセル、入力欄に入れた文字、アラート | <span className="text-sm">みほん同人誌</span> |
| ラベル | 14px | 太字 | ボタン、入力欄の名前、テーブルの見出しの行 | <span className="text-sm font-bold">注文数量</span> |
| 補足 | 12px | 標準 | 見出しの補足、入力欄のエラー、バッジ | <span className="text-xs">2784702901978</span> |

- 太字は 700、標準は 400。
- テーブルの中の文字は、本文と同じにする。テーブルの見出しの行は、ラベルにする。
- text のボタンは、ボタンでも本文の大きさと太さにし、下線を付ける。
- 本文の中で強調するときは、大きさを変えずに太字にする。選んでいるタブや、確認ダイアログの対象の値がこれに当たる。
- 即売会のレジの合計金額のように、大きく見せる数字には、この表にない大きさを使ってよい。
- 補足の 12px は、ボタンには使わない。
