# 文言と書式

画面に書く言葉と、金額や日時の書き方です。

## 句点

文には句点（。）を付け、文でないものには付けません。

| 付ける | 付けない |
|---|---|
| アラート、何もないときの文言、ダイアログの本文、入力欄の下のエラー | 見出し、項目名、ボタン、バッジ、単語の箇条書き、例として挙げた名詞 |
| 発注を登録しました。 | 新規発注を登録 |

文が 2 つ以上続くときは、最後の文を含め、どの文にも句点を付けます。

- 発注がありません。「新規発注を登録」から登録できます。

## アラートの文言

アラートの文言は、何が起きたかと、次に何をすればよいかを、簡潔に書きます。ボタンの横に置くアラートでも、浮かせて重ねるアラートでも、2 行に収まる長さにします。サーバーの応答などの技術的な中身は画面に出さず、ブラウザのコンソールに出します。

- 発注を登録できませんでした。通信状態を確認して、もう一度登録してください。

## ボタンの名前を書くとき

文の中で画面のボタンを指すときは、ボタンと同じ言葉を「」で囲みます。

- 「新規発注を登録」から登録できます。

## 確認のボタンの言葉

確認ダイアログでは、閉じるボタンを「やめる」、確定のボタンを実際に起きること（「削除」「取り消す」「破棄する」）にします。詳しくは[確認](?path=/docs/デザインパターン-確認--docs)を見てください。

## 金額

「¥」を前に付け、3 桁ごとにカンマを入れます。

| 書き方 | 例 |
|---|---|
| 金額 | ¥1,000 |
| 0 円 | ¥0 |
| 負の金額（レジ金の不足など） | -¥1,000（「-」は「¥」の前） |
| 割り算をした値（発注の単価など）のように、小数が出うるもの | ¥245.9、¥1.0（小数 1 桁） |

金額は整数で記録するので、ふつうは小数が出ません。小数が出うるものは、小数 1 桁で書きます。

金額の入力欄は、欄の左に「¥」を置きます。

## 冊数

冊数の入力欄は、欄の右に「冊」を置きます。

## 金種

硬貨と紙幣の種類の名前は、「円玉」「円札」を付けて書きます。金額の「¥」は付けません。

| 種類 | 例 |
|---|---|
| 硬貨 | 1円玉、5円玉、10円玉、50円玉、100円玉、500円玉 |
| 紙幣 | 1,000円札、5,000円札、10,000円札 |

## 日時

| 書き方 | 例 |
|---|---|
| 日時 | 2026/01/05 09:00 |
| 日付だけ | 2026/01/05 |
| 時刻だけ（その日のうちの記録） | 09:00 |

- 年/月/日の順で、「/」で区切る。
- 時刻は 24 時間表記にする。
- 月、日、時は 2 桁にそろえる。
